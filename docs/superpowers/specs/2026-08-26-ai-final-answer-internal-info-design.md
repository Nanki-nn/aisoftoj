# AI 最终回答隐藏平台内部信息设计

## 目标

AI 助手的最终回答只呈现面向学习者的结论、依据和建议，不出现平台内部实现信息。

以下内容不得出现在最终回答中：

- 工具名，例如 `get_question`
- 接口名或接口路径
- 题目 ID、记录 ID、会话 ID 等平台内部标识
- “数据来源：某工具/接口”等内部来源说明

## 范围

本次只调整最终回答的生成约束，不修改前端的“正在处理 / 完成步骤”区域，也不改变工具调用、事件流、数据存储或 API 协议。

## 方案

修改 AI 系统提示词：

1. 保留基于平台真实数据回答、信息不足时不得编造的要求。
2. 删除“引用题目或练习数据时应说明数据来源”的要求。
3. 明确规定最终回答不得披露工具名、接口名、接口路径、内部 ID 或平台数据来源说明。
4. 要求将内部查询结果自然转述为面向学习者的内容。

该约束放在服务端系统提示词中，使流式回答和持久化的最终消息遵循同一规则，无需在前端用易误删正常内容的正则表达式过滤。

## 数据流与错误处理

工具仍按现有流程读取题目和练习数据，模型仍可在内部使用这些信息。只有最终回答的表达方式发生变化。若信息不足，回答应说明“当前信息不足”，但不能通过暴露内部工具、接口或 ID 来解释原因。

## 测试

增加系统提示词测试，验证提示词：

- 明确禁止最终回答出现工具名、接口名、内部 ID 和平台数据来源说明。
- 不再要求回答说明数据来源。
- 仍保留“信息不足时明确说明、不得编造”的可靠性要求。

不新增前端测试，因为本次不改变前端渲染行为。
