# GitHub Star 引导设计

## 目标

在“作者经历”模块中提高 GitHub 仓库入口的可见度，引导更多用户访问仓库并点击 Star，同时保留“阅读完整备考经验”的原有入口。

## 范围

- 仅修改 `aisoftoj-front/src/components/LearningLanding.tsx` 中的作者经历模块。
- 删除原有三个考试结果卡片，并将备考经验链接右对齐；不调整其他页面区域。
- 不读取或展示实时 Star 数量。

## 交互与内容

原有“阅读完整备考经验”文字链接保持不变，继续在新标签页打开：

`https://github.com/Nanki-nn/aisoftoj/blob/main/guides/%E7%B3%BB%E7%BB%9F%E6%9E%B6%E6%9E%84%E5%B8%88%E5%A4%87%E8%80%83%E7%BB%8F%E9%AA%8C.md`

在完整作者经历卡片下方新增独立支持条，使其与备考正文完全分离：

- 提示文案：`觉得项目有帮助？`
- 主按钮文案：`去 GitHub 点 Star`
- 主按钮链接：`https://github.com/Nanki-nn/aisoftoj`
- 主按钮在新标签页打开。
- 使用 lucide-react 的 `Star` 与 `ExternalLink` 图标，不新增资源依赖。

## 视觉设计

- 支持条内部使用纯白背景，不使用黄色填充、渐变或装饰光晕。
- 使用细琥珀色边框和轻微暖色阴影，使其融入现有作者经历卡片。
- 提示文案使用暖棕色强调。
- Star 按钮使用实色琥珀背景和白色文字，作为区域内唯一强视觉焦点。
- 保留合理圆角，但不修改 Shadcn `ui/` 目录中的组件。

## 响应式与无障碍

- 桌面端支持条横向排列：左侧提示文案，右侧 Star 按钮。
- 移动端改为纵向排列，按钮占满可用宽度，避免文字拥挤。
- 外链保留 `target="_blank"` 与 `rel="noreferrer"`。
- 图标使用 `aria-hidden="true"`，并为新标签页行为提供屏幕阅读器提示。
- 提供清晰的 hover 与 `focus-visible` 状态。
- 不添加持续动画，因此无需额外处理减少动态效果偏好。

## 验证

- 运行前端构建或 TypeScript 检查，确认新增图标和 JSX 正常编译。
- 检查桌面端与移动端布局。
- 验证备考经验链接和 GitHub 仓库链接均返回成功响应，并在新标签页打开。
- 确认支持条背景为纯白，页面中不出现额外黄色填充或光晕。
