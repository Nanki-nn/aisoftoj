# AI 助手侧栏拖拽调宽设计

## 目标

让桌面端用户能够从 AI 助手面板左边缘向左拖动，临时扩大对话阅读空间，同时保持面板右侧贴紧视口。移动端和中等宽度设备继续使用现有固定宽度与遮罩交互。

## 交互设计

- 面板默认宽度保持 400px，避免改变现有首次打开体验。
- 仅在 Tailwind `xl` 桌面断点显示左边缘拖拽热区。
- 向左拖动时面板变宽，向右拖动时面板变窄；面板右边缘始终固定。
- 宽度下限为 400px，上限为 720px，同时保证主页面至少保留 320px 可见区域。
- 拖拽热区绝对定位在面板左边缘，不占用内容宽度；使用 10px 命中宽度和 `touch-action: none`。视觉上保持克制：默认只显示现有边框，悬停、聚焦或拖动时显示蓝色强调线。
- 拖动期间使用列调整光标并禁止页面文本选择，结束拖动后恢复。
- 拖拽热区可聚焦并提供“调整 AI 助手宽度”的名称，使用 `role="separator"`、`aria-orientation="vertical"` 以及动态 `aria-valuemin`、`aria-valuemax`、`aria-valuenow`。左方向键增宽、右方向键减宽，每次调整 24px；达到动态边界时约束到整数边界值，并同步更新 ARIA 数值。
- 本次宽度仅保存在组件当前生命周期中；刷新页面后恢复 400px，不新增持久化设置。

## 实现边界

- 修改 `AIAgentPanel` 组件自身，不改通用 Shadcn UI 组件。
- 使用 Pointer Events 统一支持鼠标和触控笔输入，不引入新的依赖。开始拖动时捕获 pointer，并处理 `pointerup`、`pointercancel`、`lostpointercapture` 和组件卸载；清理时恢复拖动前的 `cursor` 与 `user-select` 页面样式。
- 动态宽度通过 React 状态保存。仅当 `xl` 媒体查询匹配时应用内联 `width`；`< sm` 使用全宽，`sm` 至 `xl` 固定为 400px，返回 `xl` 后恢复本次页面会话中保存的桌面宽度。
- 视口尺寸变化时重新计算动态上限并约束桌面宽度，避免窗口缩小后面板超过新的上限；ARIA 最大值和当前值同步更新。
- 关闭面板时保留本次页面会话内的宽度，重新打开无需重复调整。

## 验证

- 前端 TypeScript/Vite 生产构建通过。
- 桌面视口验证默认宽度、向左拖宽、向右缩窄、上下限和右侧贴边。
- 验证手柄键盘操作及 ARIA 数值更新。
- 移动端视口验证面板仍为全宽，且不显示拖拽手柄。
- 在桌面调到最大宽度后依次缩到 `sm` 至 `xl`、再缩到 `< sm`，最后放回 `xl`：分别验证固定 400px、全宽和恢复经新上限约束后的桌面宽度，并检查动态 `aria-valuemax`。
- 检查面板打开、关闭和遮罩行为无回归。
