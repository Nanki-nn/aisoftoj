# AI 助手侧栏拖拽调宽设计

## 目标

让桌面端用户能够从 AI 助手面板左边缘向左拖动，临时扩大对话阅读空间，同时保持面板右侧贴紧视口。移动端和中等宽度设备继续使用现有固定宽度与遮罩交互。

## 交互设计

- 面板默认宽度保持 400px，避免改变现有首次打开体验。
- 仅在 Tailwind `xl` 桌面断点显示左边缘拖拽热区。
- 向左拖动时面板变宽，向右拖动时面板变窄；面板右边缘始终固定。
- 宽度下限为 400px，上限为 720px，同时保证主页面至少保留 320px 可见区域。
- 拖拽热区视觉上保持克制：默认只显示现有边框，悬停、聚焦或拖动时显示蓝色强调线。
- 拖动期间使用列调整光标并禁止页面文本选择，结束拖动后恢复。
- 拖拽热区使用 `separator` 语义，可通过左右方向键每次调整 24px，并暴露当前值与上下限。
- 本次宽度仅保存在组件当前生命周期中；刷新页面后恢复 400px，不新增持久化设置。

## 实现边界

- 修改 `AIAgentPanel` 组件自身，不改通用 Shadcn UI 组件。
- 使用 Pointer Events 统一支持鼠标和触控笔输入，不引入新的依赖。
- 动态宽度通过 React 状态和内联 `width` 设置；小于 `xl` 时继续由现有 `w-full sm:w-[400px]` 类控制。
- 视口尺寸变化时重新约束当前宽度，避免窗口缩小后面板超过新的上限。
- 关闭面板时保留本次页面会话内的宽度，重新打开无需重复调整。

## 验证

- 前端 TypeScript/Vite 生产构建通过。
- 桌面视口验证默认宽度、向左拖宽、向右缩窄、上下限和右侧贴边。
- 验证手柄键盘操作及 ARIA 数值更新。
- 移动端视口验证面板仍为全宽，且不显示拖拽手柄。
- 检查面板打开、关闭和遮罩行为无回归。
